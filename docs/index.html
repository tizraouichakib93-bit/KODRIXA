            How it works
            
Three steps. No magic claims.

          

        

        

          

            01
            
Describe or paste

            
Write what you want in plain language, or paste code you already have. Pick from the same 15-language list in every tool — searchable, with capability badges.

          

          

            02
            
Local engine or live AI

            
With no backend configured, the bundled engine composes results in your browser and the header says “Demo mode”. Connect backend/server.py with a provider key for live AI — the key never touches frontend code.

          

          

            03
            
Edit, copy, ship

            
Results land in a syntax-highlighted, fully editable editor with live line counts. Copy to clipboard, download a real file, apply fixes or walk the explanation — then build.

          

        

      

    


    

      

        

          

            Transparency
            
What’s real, and what’s demo.

          

          
KODRIXA never pretends an AI answered when it didn’t. The mode pill in the header always tells you which engine produced a result.

        

        

          

            
Demo mode Bundled engine

            
Generation composes programs from an intermediate representation across 13 general-purpose languages, SQL and HTML/CSS. Translation covers a structural subset (loops, conditionals, functions, assignments, output) and reports anything outside it. Debugging is a syntax heuristic, not a compiler. Explanations label lines beyond the built-in guide. Everything runs locally — no network, no keys, no pretending.

          

          

            
Live AI Secure backend

            
Run python backend/server.py with KODRIXA_API_KEY set in the server environment (optionally KODRIXA_API_BASE and KODRIXA_MODEL). The browser talks only to the same-origin /api/* proxy; the provider key stays server-side and is never shipped to frontend JavaScript. The header switches to “AI connected” automatically.
